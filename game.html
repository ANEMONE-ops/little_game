记忆翻牌

游戏说明：

1. 点击卡片翻开，记住卡片上的图案

2. 每次可以翻开两张卡片

3. 如果两张卡片图案相同，它们会保持翻开状态

4. 如果不同，卡片会翻回去

5. 找出所有相同的卡片对即可获胜

打地鼠

得分: 0
时间: 30秒

游戏说明：

1. 地鼠会随机从洞中冒出

2. 快速点击地鼠获得分数

3. 每击中一只地鼠得10分

4. 游戏时间为30秒

5. 尽可能获得更高的分数

贪吃蛇

得分: 0

游戏说明：

1. 使用方向键控制蛇的移动

2. 吃到食物可以增长身体并获得分数

3. 避免撞到墙壁或自己的身体

4. 随着得分增加，蛇的移动速度会加快

5. 尽可能获得更高的分数

俄罗斯方块

得分: 0

游戏说明：

1. 使用方向键控制方块移动

2. 上方向键旋转方块

3. 下方向键加速下落

4. 填满整行可以消除并获得分数

5. 方块堆积到顶部游戏结束

拼图游戏

游戏说明：

1. 点击空白块相邻的拼图块进行移动

2. 将所有数字按顺序排列

3. 空白块应该在右下角

4. 用最少的步数完成拼图

5.切勿点击打乱键！！！

游戏说明：

1. 点击"开始游戏"按钮开始
